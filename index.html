Antes de tudo

O que é IA, em 1 minuto

Inteligência Artificial é um sistema que aprende padrões a partir de muitos exemplos e usa esses padrões para fazer tarefas que antes exigiam uma pessoa: traduzir, reconhecer voz, escrever, resumir.

Como um chatbot "pensa"

Um modelo de linguagem (LLM) lê o texto e calcula qual é a próxima palavra mais provável. Repetindo isso milhares de vezes, ele escreve respostas inteiras.

1.1

Tradução automática

Os tradutores modernos usam redes neurais: em vez de trocar palavra por palavra, leem a frase inteira e entendem o contexto. Em 2024, o Google Tradutor ganhou 110 idiomas novos de uma vez, com ajuda do modelo PaLM 2.

Experimente: escolha uma frase
PT · Português

EN · Inglês

ES · Espanhol

JA · Japonês

Ferramentas
  • Google Tradutor textos, sites, câmera (traduz placas e manuais) e conversa por voz
  • DeepL traduções mais naturais para textos longos
  • Microsoft Translator legendas em tempo real numa conversa em grupo
  • Chatbots (ChatGPT, Claude, Gemini) você pode pedir o tom: formal, técnico, para criança…
Dicas de quem usa bem
  1. Escreva frases curtas e completas.
  2. Traduza de volta para o português para conferir o sentido.
  3. Termos técnicos e gírias: revise com alguém da área.

Assistentes virtuais

Siri (2011), Alexa (2014), Google Assistente/Gemini e Copilot ouvem um pedido, descobrem a intenção e executam uma ação. Por trás de um simples "me lembra de…" existem cinco etapas.

1.3

Chatbots

Um chatbot é um programa que conversa por texto. Existem dois tipos: o de regras (menu de opções fixas) e o com IA generativa, que entende linguagem natural, mesmo com erros de digitação e gírias.

Oi! Perdi a aula de ontem, o que foi passado? Tem atividade?
Regras × IA
RegrasIA
Entende frases livres❌✅

Onde você encontra: atendimento de bancos e lojas, WhatsApp de empresas, suporte técnico, triagem em clínicas, secretarias de escola.
Atenção: o bot com IA só sabe sobre a sua escola se for conectado aos dados reais dela. Sem isso, ele pode "alucinar", ou seja, inventar uma resposta convincente.
1.4

Geração de conteúdo

A IA generativa cria coisas novas a partir de um pedido em texto: redações, imagens, músicas, vozes, vídeos e até programas. Geradores de imagem usam modelos de difusão: começam com ruído puro e, passo a passo, vão removendo o ruído na direção do que você descreveu.

Prompt

"Esfera laranja sobre pedras brancas, luz suave de estúdio, estilo 3D minimalista"

passo 0/40ruído puro
📝 TextoChatGPT, Claude, Gemini: redações, e-mails, roteiros
🖼️ ImagemMidjourney, Adobe Firefly, Canva: artes e cartazes
🎵 ÁudioSuno (música), ElevenLabs (voz)
🎬 VídeoSora, Veo, Runway: cenas a partir de texto
💻 CódigoClaude Code, Codex, GitHub Copilot
📊 SlidesGamma, Canva e… esta apresentação!
Regras de ouro: confira os fatos, avise quando usou IA, respeite direitos autorais e nunca crie imagens falsas (deepfakes) de pessoas reais.
1.5

Resumo de texto

Existem dois jeitos de resumir. O extrativo escolhe as frases mais importantes e copia do original. O abstrativo (o que os chatbots fazem) reescreve a ideia com palavras novas.

0 palavras
Prompt prontoResuma em 5 tópicos para um aluno do 1º ano, com palavras simples.
Para estudarResuma e depois me faça 3 perguntas para eu testar se entendi.
FerramentasNotebookLM (resume PDFs e gera áudio), ChatGPT/Claude com arquivo anexado, resumo de vídeos do YouTube
1.6

Elaboração de prompts

Prompt é o pedido que você faz para a IA. A regra de ouro: escreva como se estivesse explicando para um colega novo e inteligente, que não sabe nada sobre você nem sobre a tarefa.

Extra

Agentes de IA: da conversa à ação

Um chatbot responde. Um agente age: recebe um objetivo, usa ferramentas (arquivos, internet, programas), confere o resultado e repete até terminar. Exemplos: Claude Code (Anthropic) e Codex (OpenAI), que trabalham direto no seu computador.

O ciclo do agente
🎯Pensar
🛠️Agir
👀Observar
🔁Repetir
ObjetivoOrganizar as fotos do projeto por mês
O que o agente está fazendo
    🛠️ Ferramentasler e criar arquivos, rodar comandos, pesquisar na web
    🔌 Conectores (MCP)pontes para apps como GitHub, Google Drive, Figma e Canva
    📚 Skillsreceitas reutilizáveis que ensinam o agente a fazer algo do seu jeito
    👥 Subagentesajudantes que fazem uma parte do trabalho em paralelo

    Claude Code e Codex na prática

    Você descreve o que quer em português e o agente planeja, escreve os arquivos, testa e publica. Esta apresentação foi criada assim: com um pedido ao Claude Code, publicada no GitHub Pages.

    Claude Code (Anthropic): app para desktop, extensão do VS Code ou terminal:

    npm install -g @anthropic-ai/claude-code

    Skills: ensine uma vez, use sempre

    Uma skill é uma pasta com um arquivo SKILL.md: instruções em texto comum, e opcionalmente modelos e scripts. O agente lê só a descrição e carrega a skill sozinho quando o pedido combina com ela.

              Cuidados
              
    Usando IA com responsabilidade
    
              
    A IA é uma ótima ajudante, mas a responsabilidade pelo trabalho continua sendo sua.
    
            
    
            
    
              
    
                
    🌀 AlucinaçãoA IA pode inventar fatos, datas e fontes com total confiança. Confira sempre.
    
                
    🔒 PrivacidadeNão cole dados pessoais (CPF, telefone, notas). A LGPD (Lei 13.709/2018) protege esses dados.
    
                
    ⚖️ ViésA IA aprende com textos humanos e pode repetir preconceitos. Leia com olhar crítico.
    
                
    ✍️ AutoriaDiga quando usou IA. A UNESCO (2023) recomenda regras claras e idade mínima de 13 anos para uso em sala.
